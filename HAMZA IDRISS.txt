
# SpendWise - Personal Finance Dashboard

## Project Description
SpendWise is a personal finance dashboard designed to help users monitor their financial activities. It displays total balance, income, expenses, monthly spending, savings goals and recent transactions.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Web Design
- GitHub
